Google Sign-In Activation

How real-world Google OAuth works

In every production app, Google requires a registered OAuth Client ID before opening the Gmail account picker. Once added, Google's popup will open instantly with your logged-in Google account!

2-Minute Quick Setup
  1. Open Google Cloud Console → Credentials
  2. Create an OAuth client ID (Web application)
  3. Add to Authorized JavaScript origins:
    https://myspendwise-app.vercel.app
    http://localhost:5000
  4. In Vercel → Settings → Environment Variables, add:
    GOOGLE_CLIENT_ID = your-id.apps.googleusercontent.com
